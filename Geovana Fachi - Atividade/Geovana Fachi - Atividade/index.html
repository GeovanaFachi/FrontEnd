Atividade — Customização do Wireframe com CSS

Utilize o arquivo HTML disponibilizado pelo professor e desenvolva sua própria estilização utilizando CSS.

O objetivo é transformar a estrutura HTML em uma página visualmente organizada, utilizando as propriedades CSS trabalhadas em aula.

Propriedades obrigatórias

  • border — aplicação de bordas;
  • width — definição de largura;
  • height — definição de altura;
  • text-align — alinhamento dos textos;
  • color — definição das cores dos textos;
  • font-size — definição do tamanho das fontes;
  • font-weight — definição do peso das fontes;
  • font-family — definição da família tipográfica;
  • background-color — definição das cores de fundo.

Orientações

As propriedades deverão ser aplicadas de maneira coerente com a estrutura da página e utilizadas para personalizar os diferentes elementos do projeto.

Utilize sua criatividade na escolha de cores, fontes, tamanhos, bordas e alinhamentos, mantendo a organização e a legibilidade da página.
